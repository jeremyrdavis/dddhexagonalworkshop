# Product Mission

## Problem

Python developers lack access to hands-on, practical DDD and Hexagonal Architecture workshops. The existing Java/Quarkus workshop has proven effective, but limits the audience to Java developers. A Python port makes these architectural patterns accessible to the broader Python community while demonstrating that DDD is language-agnostic.

## Target Users

- Professional Python developers wanting to learn DDD and Hexagonal Architecture
- Conference and meetup attendees who prefer Python for hands-on exercises
- CS students learning software architecture patterns

## Solution

A hands-on workshop where participants learn by doing — not by reading theory. The workshop provides stubbed Python classes with step-by-step implementation guides, following the same proven format as the Java version. Participants build a complete conference attendee registration system, implementing the full flow from HTTP requests through domain logic to database persistence and event publishing.
